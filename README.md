# AeroLearn

AeroLearn is a static educational web platform for Aerospace Engineering.
It uses Astro, MDX, and vanilla CSS for a fast, accessible, and privacy-first learning experience.

## Features

- **Static Generation:** Deploys easily to Cloudflare Pages (run npm run build to get the dist directory).
- **Interactive MDX:** Rich content authoring with interactive components (e.g., worked examples, quizzes).
- **Mathematical Rendering:** Support for equations via KaTeX (remark-math + rehype-katex).
- **Local Progress Tracking:** Privacy-first tracking of your learning progress using localStorage.

## Setup
Install dependencies and run the dev server.
